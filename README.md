# 🚀 Retos_JavaScript

Colección de ejercicios y retos prácticos de JavaScript, organizados por guías. Cada carpeta corresponde a un tema específico, con ejercicios que refuerzan el concepto y su depuración (debugging) ante errores comunes.

## 📖 Contenido por guía

### Guia-1 — Fundamentos
Bases del lenguaje: tipos de datos y variables, operadores (incluyendo ternarios), estructuras condicionales (`if/else`, `switch`), ciclos (`for`, `while`, `do while`) y funciones (declaración básica, con parámetros y valores de retorno).
