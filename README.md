# 🚀 Retos_JavaScript

Colección de ejercicios y retos prácticos de JavaScript, organizados por guías. Cada reto refuerza un concepto del lenguaje, con foco en identificar y corregir errores comunes.

## 📂 Estructura
```
Retos_JavaScript/
├── Guia-1/
└── Guia-2/
```
### Guia-1
Fundamentos de JavaScript: variables, funciones, arrays y sus métodos (`map`, `filter`, `forEach`, `some`, `every`, `find`), y debugging de errores comunes (tipos de dato, callbacks mal invocados, nombres de propiedades inconsistentes).

### Guia-2
Conceptos intermedios/avanzados:

- **Desestructuración, Spread y Rest** — extracción de propiedades, eliminación de campos sensibles, fusión de objetos.
- **Funciones puras y de orden superior** — refactor de funciones impuras, closures.
- **Clases y POO** — herencia (`extends`/`super`), métodos estáticos, campos privados (`#campo`) con getters/setters.
- **Manejo de errores** — clases de error personalizadas, `try/catch` con `instanceof`.
- **Recursión** — conteo sin bucles, aplanado de arrays anidados.
- **Asincronía** — Promises, `async/await`, ejecución secuencial vs paralela, `Promise.race`.
- **Módulos ES** — `import`/`export`, named exports vs default export.

## 🎯 Objetivo

Practicar JavaScript resolviendo retos progresivos, detectando errores típicos (condiciones lógicas invertidas, `return` faltantes, nombres de variables inconsistentes) y aplicando buenas prácticas.

## 🛠️ Cómo ejecutar

```bash
node ruta/al/archivo.js
```

> Los ejercicios de módulos (`import`/`export`) requieren `"type": "module"` en el `package.json`, o extensión `.mjs`.
